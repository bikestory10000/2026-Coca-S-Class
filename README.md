# 2026 압축보카 S 클래스 · 동의어

민쌤영어 동의어 4지선다 1,913문항을 20개 세트로 구성한 정적 HTML 사이트입니다. 화면과 풀이 기능은 보카 크로니클 20을 기준으로 만들었습니다.

## GitHub Pages에 올리기

이 폴더의 `index.html`, `set-01.html`부터 `set-20.html`까지를 저장소 루트에 올리세요. GitHub Pages의 배포 원본을 해당 브랜치의 루트로 지정하면 됩니다. 각 HTML에는 CSS·JS가 들어 있으며, `assets/`와 `tools/`는 나중에 수정할 때 쓰는 원본입니다.

## 기능

정답 채점, 해석·어휘 풀이, 틀린 문항과 저장한 문항 보기, 검색, 문항 지도, 인쇄, 발음, 화면 설정, 기록 백업을 지원합니다. 기록은 브라우저에 저장됩니다.

문항 데이터는 사용자가 제공한 두 TXT에서 가져왔습니다. 영영정의와 어원·구성 설명은 추가 자료를 바탕으로 보완했습니다. 원문 문장·보기·정답·해석·한국어 어휘 뜻은 제공된 TXT를 그대로 사용합니다.

## 수록 범위와 풀이 기록

새 원본 파일에는 1–1913번이 연속해서 들어 있습니다. 1–19세트는 각 100문항, 20세트는 1901–1913번의 13문항입니다. 영영정의와 어원·표현 구성 설명은 밑줄 어휘와 보기 4개 모두에 포함됩니다. 자료 출처는 `출처_안내.md`, 원본 대조 결과는 `검증결과.json`을 참고하세요.

872문항 버전과 문항 번호가 달라 풀이 기록은 별도로 저장됩니다. 예전 버전의 기록을 이 버전으로 가져올 수 없습니다.
